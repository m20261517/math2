# 원기둥·원뿔·구 구별 앱

초등학교 6학년 수학에서 배우는 **원기둥, 원뿔, 구**를 인공지능으로 구별해 보는 학습 앱입니다.

## 앱 소개

카메라로 입체도형을 비추거나 사진을 올리면 티처블머신 이미지 분류 모델이 도형을 분석하여 다음 중 하나로 알려 줍니다.

- **원기둥**: 위와 아래가 같은 원이고 옆면이 둥글게 이어진 입체도형
- **원뿔**: 원 모양의 밑면과 뾰족한 꼭짓점이 있는 입체도형
- **구**: 공처럼 둥글며 꼭짓점과 모서리가 없는 입체도형

분류 결과의 확률이 **70% 미만**이면 정확하지 않을 수 있으므로 **“잘 모르겠어요”**라고 표시합니다. 이를 통해 학생들이 인공지능의 예측 결과를 확인하면서 도형의 특징도 함께 복습할 수 있습니다.

## 구현 앱 바로가기

👉 [원기둥·원뿔·구 구별 앱 실행하기](https://m20261517.github.io/math2/)

## 주요 기능

- 카메라를 이용한 실시간 도형 분류
- 사진 파일 올리기를 이용한 도형 분류
- 원기둥, 원뿔, 구의 분류 결과와 확률 표시
- 확률이 70% 미만일 때 “잘 모르겠어요” 표시
- 사진을 외부 서버로 보내지 않고 브라우저에서 처리
- 스마트폰과 컴퓨터에서 사용할 수 있는 반응형 화면

## 사용 방법

1. [앱 실행하기](https://m20261517.github.io/math2/)를 누릅니다.
2. **카메라 시작**을 누르고 카메라 사용 권한을 허용합니다.
3. 도형을 카메라에 보여 주거나 **사진 올리기**를 선택합니다.
4. 화면에 나타나는 분류 결과와 확률을 확인합니다.

> 카메라 기능은 브라우저 보안 정책에 따라 HTTPS 환경에서 사용하는 것이 좋습니다.
