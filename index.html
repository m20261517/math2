사진을 찍거나 올리면 원뿔, 원기둥, 구 중 무엇인지 알려줘요.

사진은 외부로 보내지 않고 이 기기에서만 처리돼요.

  1. 모델 로딩이 끝날 때까지 잠깐 기다려요.
  2. 카메라를 시작하고 사진을 찍거나, 파일 업로드로 사진을 선택해요.
  3. 분석 결과를 확인해요.

현재 file:// 방식으로 열려 있어요. 브라우저 보안 정책 때문에 모델/카메라가 동작하지 않을 수 있어요. GitHub Pages 또는 로컬 HTTP 서버에서 열어 주세요.
